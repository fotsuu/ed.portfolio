# Project Brief: Eric Diamante Developer Portfolio

## Overview
A modern, responsive, and performance-focused developer portfolio for **Eric Diamante** — Software & Web Developer, AI Workflows & Data Specialist based in Digos City, Philippines.

## Goals & Objectives
1. **Showcase Real-World Systems**: Highlight complex GovTech land disposition (DENR Land Inventory System) and intelligent agricultural algorithms (FeedWise poultry feed formulation).
2. **Demonstrate Technical Craftsmanship**: Zero-build, fast-loading, pure HTML/CSS/JavaScript architecture with accessible components and responsive layouts.
3. **Facilitate Contact & Hiring**: Direct CV download/preview, direct email access, and a zero-friction contact form that drafts messages directly for the visitor.

## Core Requirements
- **Zero Build Toolchain**: Must run immediately via standard static web servers without Node.js build steps or npm installations.
- **Accessibility & UX**: Fully keyboard-navigable dialogs, WCAG compliant contrast in both light and night modes, focus management, and reduced-motion support.
- **Zero FOUC (Flash of Unstyled Content)**: Pre-render theme detection script in `<head>` to ensure instantaneous theme application.
- **Maintainable & Clean Code**: Semantic HTML5 markup, modular CSS architecture using CSS custom properties, and vanilla ES6+ JavaScript.
